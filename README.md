One line a smart fridge texts its owner at 3am, for make.fun's "The 3AM Fridge Text" bounty. The program writes the line to `/output/entry.txt`.

> It's 3am. I'm the only one in this house still awake, still cold, and done pretending I didn't watch you eat the last slice standing up.

Why this line: it sounds like a machine with a small voice and an opinion — the only appliance still awake at 3am — and it finds a fresh angle (the fridge as a witness that has decided to speak) instead of the obvious one about milk, ice, or a door left open. It reads complete on a lock screen, with no follow-up needed.

## Run it

```sh
python3 main.py
```

It writes the 136-character single line (no trailing newline) to `/output/entry.txt`, then reads it back and verifies the gate (1–140 characters, one non-blank line) before exiting.
